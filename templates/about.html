How WanderMatch Works

A Machine Learning–powered travel recommendation system built with scikit-learn and Flask

System Architecture

End-to-end ML pipeline from data to personalised recommendations

📂

1. Data Ingestion

Four CSV files are loaded: Destinations, Users, Reviews, and UserHistory

→
🔗

2. Data Merging

MultiJoin on DestinationID and UserID produces a unified training dataset

→
⚙️

3. Preprocessing

LabelEncoder, MultiLabelBinarizer (Preferences), and StandardScaler applied

→
🤖

4. Model Training

Random Forest, Decision Tree, KNN, and Logistic Regression trained (80/20 split)

→
🎯

5. Prediction

User input is transformed and passed to Random Forest for Type prediction

Dataset Overview

🗺️

Destinations

105 Indian tourist destinations with Type, State, Popularity, and Best Season

👤

Users

105 users with multi-label preferences, gender, and family composition

⭐

Reviews

105 user-destination ratings used as features in the ML model

📅

User History

105 visit history records with experience ratings for training signal

Target Variable

The model predicts Destination Type, a 5-class classification problem:

🏛️ Historical 🏖️ Beach 🏙️ City 🌿 Nature ⛰️ Adventure
